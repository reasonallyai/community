# Reasonally community

Every leading model. One API key.

This is the public feedback hub for [Reasonally](https://reasonally.ai). Share bug reports, propose features, and help shape what we build next.

## Contribute feedback

[Report a bug](https://github.com/reasonallyai/community/issues/new?template=bug_report.yml) · [Request a feature](https://github.com/reasonallyai/community/issues/new?template=feature_request.yml) · [Share an idea](https://github.com/reasonallyai/community/issues/new?template=idea.yml)

Use the **Issues** tab and select **New issue** to choose a bug report, feature request, or idea form. Search existing issues first; add a reaction or your use case to an existing request when it matches.

For bug reports, include the steps to reproduce, the expected behavior, and a small redacted example. For feature requests, describe the problem you want to solve and the workflow it would improve.
